## Build targets

This Flutter project supports Android, iOS, and web.

- Android APK: `flutter build apk --release`
- iOS app: `flutter build ios --release --no-codesign`
- Web site: `flutter build web --release`

If you want to build all targets locally, run:

- macOS / Linux: `./build_all.sh`
- Windows: `build_all.bat`

> Note: building iOS requires a Mac with Xcode installed.

### GitHub Pages website

After `deploy-web` runs successfully, the app is published from the `gh-pages` branch. The public URL is typically:
